# Code of Conduct

## Our Pledge
We want to create a welcoming, friendly and respectful environment for everyone who interacts with this project.

## Expected Behavior
- Be respectful and considerate
- Use inclusive and friendly language
- Provide constructive feedback
- Focus on improving the project
- Assume good intentions

## Unacceptable Behaviors
- Harassment, insults or personal attacks
- Discrimination of any kind
- Trolling, spamming or derailing discussions
- Sharing harmful or malicious content
- Aggressive or disrespectful communication

## Reporting Issues
If you experience or witness unacceptable behavior, please report it privatly:
- Email: [Contact me↗[Email]](mailto:MrSchildkroet@outlook.de)

All reports will be handled confidentially.

## Enforcement
Project maintainers may take appropriate action, including:
- warnings
- closing issues or PRs (Pull Requests)
- temporary or permanent bans

We aim to keep this project safe, respectful and enjoyable for everyone.
