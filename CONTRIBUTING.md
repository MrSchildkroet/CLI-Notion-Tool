# Contributing to Notion-CLI

Thank you for your interest in contributing to this project!
This project follows a clean and structured TypeScript architecture, so please read the following guidelines before opening a PR (Pull Request).

---

## 🐛 Issues
If you find a bug or want to request a feature:

1. Check if an issue already exists.
2. Create a new issue with:
    - a clear discription
    - steps to reproduce
    - expected behavior
    - environment info (Node version, OS, etc.)

---

## Development Setup
1. Clone the repository
2. Install dependencies:

    PowerShell (Windows), Bash/zsh (Linux/MacOS)

    ```powershell
    npm install
    ```

3. Run the CLI in dev mode:

    PowerShell (Windows), Bash/zsh (Linux/MacOS)
    ```powershell
    npm run dev
    ```

---

## Running Tests & Checks
Before commiting, make sure everything passes:

PowerShell (Windows), Bash/zsh (Linux/MacOS)
    
    npm run format
    npm run lint
    npm run build

---

## Code Style
This project uses:
- **ESLint** for linting
- **Prettier** for formatting
- **TypeScript** strict mode

Please ensure your code follows the existing style.

--- 

## Pull Requests
When submitting a PR (Pull Request)
- Use a clear title and description
- Referenc3e related issues
- Keep PRs docused (one feature/fix per PR)
- Make sure all checks pass
- No unrelated formatting changes

---

## ❤️ Thank you

Your contributions help improve this project for everyone.
Thank you for taking the time to help!
